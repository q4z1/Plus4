# The teams' flags for the title, drawn by tools/mkflags.py: each a list
# of shapes, painted in turn on a flag 3 wide and 2 high (x 0-1 across,
# y 0-1 down), separated by ";". The teams are title.s's, in its order.
# A flag is 6 x 4 multicolour cells: stripes down in thirds lie on their edges.
#
#   field C                    all of it
#   hstripes C C ...           stripes across, top to bottom (C*n: n as wide)
#   vstripes C C ...           stripes down, left to right
#   rect C x0 y0 x1 y1         a rectangle
#   cross C w [x y]            a cross, w thick (of the height), crossing at x, y
#   saltire C w [x0 y0 x1 y1]  a diagonal cross, over all of it or that box
#   ujack x0 y0 x1 y1          a Union Jack in that box
#   disc C x y r               a disc, r of the height
#   halfdisc C x y r           its lower half
#   ring C x y r w             a ring, r outside, w thick
#   star C x y r               a five-pointed star, a point up
#   diamond C x y w h          a lozenge, w and h its full size
#   band C x0 y0 x1 y1 w       a straight band, w thick
#   sprite NAME x y            a picture below, its middle at x y
#
# (Brazil's lozenge is laid on the cells, a step a cell: its green and
# yellow cannot share one.)
#
# Colours: navy, white and red every cell has (navy the title's own blue);
# one more each cell: black, yellow, gold, green, dark (green), blue,
# sky, maroon. Where a cell would need two of those, the lesser comes out
# as the nearest of its four.
#
# A sprite is drawn in square pixels, two to a multicolour pixel (so its
# rows have an even length): . see-through, N navy, W white, R red,
# K black, Y yellow, O gold, G green, D dark, B blue, S sky, M maroon.
