; picture (50 a second), so the tempo does not depend on how busy the game
; is. tools/mkmusic.py makes each song what the player reads (music.inc):
; the title's the disk's file "music", a map's part of the map's file
; (tools/mklevel.py: "music NAME" in data/<map>.txt). tools/song2wav.py
; plays one into a .wav.
;
;   song NAME          a song, which loops
;   volume N           its volume, 0-8 (the TED has one for both voices)
;   pattern NAME       a part played more than once, written once: the v1/v2
;                      lines after it are its two voices, till the next
;                      pattern or main (tools/mkmusic.py finds what comes
;                      again by itself too, and packs it)
;   main               back to the song's own voices
;   v1 / v2 NOTES      notes of voice 1 (tune) and voice 2 (accompaniment),
;                      appended line by line
;   NOTE[:LEN[.|~]]    A2 .. B7 with # or b, r = rest; LEN in 50ths of a
;                      second, the last one given if left out; a . after it
;                      plays the note staccato, for half its length, a ~
;                      tied, to its end (a note falls silent two frames
;                      before it: a short grace note would be a click and
;                      a gap). | is a bar line and means nothing. @NAME plays that
;                      voice's part of a pattern.
;
; The TED cannot go lower than about A2 (110 Hz). In the game voice 2
; gives way to sound effects while they play (engine.s).
