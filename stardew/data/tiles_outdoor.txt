; Outdoor tiles: farm, village, mountain.
;
; A tile is 8 multicolour pixels by 16 lines, four characters. Pixels:
;   .  background (grass green; the season changes it)
;   x  dark brown     o  light brown     #  the colour of the cell
; col= one colour for all four cells, top,bottom, or top-left,top-right,bottom-left,
; bottom-right. same=TILE: the characters of TILE with other colours.
; flags: solid, water, till (the hoe works here), soil, wet, door, use.
; in=farm or in=village: only the farm's or only the village's tile set has
; the tile's characters (tools/mkdata.py). Both number the tiles alike.
