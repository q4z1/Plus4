; Rooms: 20 x 11 tiles each, one screen. Every room is a file of its own on
; the disk and is loaded when the farmer walks in.
;
;   room NAME            starts a room
;   set outdoor|indoor|mine   its tile set
;   pal BG DARK LIGHT BORDER  the colours shared by all cells
;   exit N=ROOM ...      the room behind each edge
;   door X Y ROOM X Y    walking onto tile X,Y goes to tile X,Y of ROOM
;   flags farm season mine indoor
;   map                  followed by 11 lines of 20 characters

legend outdoor .=GRASS ,=GRASS2 *=FLOWERS ==PATH T=TREE b=BRANCH s=STONE w=WEEDS
